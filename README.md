# To-Do App
A simple and responsive To-Do app built with Create React App. Users can add, delete, and manage daily tasks in a structured way.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as complete
- Edit tasks

## Setup
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm start` to launch the app

## Built with
- React
- Create React App
- JavaScript
